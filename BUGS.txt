## Rejected reports

- K-27: nested hint lists match Connect once the argument convention is aligned.
- GROK-21: PySpark also rejects zero await-termination timeouts.
- OX-46: doubled backticks close and reopen quoting without changing the output.
- OX-1: Connect sends trim characters first; Spark's auxiliary constructors
  support this order. The report used the wrong constructor as its reference.
- K-2 / QWEN S-7: Spark's default SQL parser processes backslash escapes;
  doubling backslashes in generated string literals is correct.
- D-4: current PySpark permits Column/integer percentile frequency, not strings.
- Q-14 and the remaining K-51 coercion differences: explicit Columns work;
  literal convenience arguments do not establish a wrong-result bug. Spark
  registers printf and format_string with the same implementation.
- OX-5 / GROK-31 / QWEN's empty-quantile claim: the aggregate returns one row
  even for empty input; the claimed zero-row result is not a reachable case.
- OX-7: callback self-calls are caught and logged, not an indefinite deadlock.
- OX-9: Explorer command results are fixed; rows_stream promises Arrow rows,
  not command-result payloads.
- Q-6, OX-32, OX-34: tuple probabilities, sort ordinals, and string bounds in
  the positional JDBC overload are outside the declared API. JDBC string
  bounds can already be passed through generic JDBC options.

Other style complaints, invalid-input error preferences, Python-only calling
conventions, and intentional API differences remain excluded. Callback reentry,
